# Mars

An old test project for remote screen sharing.

I built it as an experiment to try out streaming a screen over the network. It's not actively maintained and isn't intended for production use. I'm keeping it here for reference.

## Build

The project is a .NET solution. Open `Mars.sln` in Visual Studio (or Rider) and build it, or run:

    dotnet build Mars.sln

## Status

Archived experiment. Expect rough edges, missing features and no guarantees.
